# Cave Explorer 🛡️

**Cave Explorer** is a 2D adventure game developed using the **Godot Engine 4**. 
This project is part of my technical journey in game development and software engineering.

## 🚀 Technologies
* **Engine:** Godot 4.6.1
* **Language:** GDScript
* **Platform:** Linux

## 🛠️ Features (Current)
* Character creation system.
* Inventory system with gold and item slots.
* Dynamic UI with custom gold/brown style.
## Mining System:
* Interaction logic for resource gathering within the cave environment.
    * Integration between mining actions and inventory updates.
